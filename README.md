Glue3D Installer
==========

Source code README

Getting Started
---------------

1. **Download the installer**

    https://github.com/SavvyScripter-GH/Glue3D-installer/releases/tag/latest/

    Run the installer and restart File Explorer. You should now be able to see glue3d scripts on your computer!

> [!NOTE]
> You need to use Droplets Utils to import .glue3d files

> [!IMPORTANT]
> For custom Glue3D syntax while editing, you need to install [this VS Code Extension](https://github.com/SavvyScripter-GH/Glue3D-vscode)
